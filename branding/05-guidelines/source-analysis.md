- All three files were inspected before creating deliverables. No unrelated identity or broken-halo motif is introduced.

- Six palette HEX values agree between the references and JSON. Numeric values below come from the JSON, not displayed pixels.

- The board associates Reckless Neue with handwritten accents, but the JSON explicitly makes that choice provisional and says signatures are separate graphics. The package preserves that qualification.
- Brand elements are the six visible motifs; meanings follow the source labels. No additional icons are fabricated.
- Proportions and spacing of each raster crop are retained. Numeric brand clear space, minimum size, tracking, font sizes, line heights and spacing scale are not defined, so no such tokens are invented.
- The separate signature additionally isolates source red pixels to exclude a nearby stone wordmark fragment. Its opaque crop shows the original context.
- All logo/element transparency is a deterministic, source-derived matte estimate, not original alpha. Original opaque crops are exact and accompany the exports. Brighter artwork pixels remain in their rendered source colors; muted source colors are not replaced by palette HEX values.
- Native dimensions are small. Convenience enlargements add no detail. True vector masters, editable logo text, isolated textures, seamless pattern tile, portrait masters and print separation remain unresolved.
- PNG-in-SVG containers reproduce exported imagery losslessly; they are deliberately named embedded-raster and are not claimed as path-based logo vectors. True vector solids are limited to specified palette fields.
